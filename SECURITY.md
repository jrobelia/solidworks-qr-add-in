# Security Policy

## Supported Versions

The latest release line (v1.x) receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/jrobelia/solidworks-qr-add-in/security/advisories/new)
— do not open a public issue.

If private reporting is unavailable, open an issue describing the problem
without exploit details and mention that it is security-sensitive; details
can be shared privately from there.
